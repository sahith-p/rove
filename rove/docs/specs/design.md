# Spec · Design (low priority until G3)

Owner: **Sahith**. Function first; polish only after the first real invoice is paid (G3).

Inspiration: **fliptexts.com**, another iMessage-first money product: white canvas, near-black text, one sparing accent, two-tone headlines (dark line, gray line), black rounded buttons with a soft shadow, soft gray rounded cards.

Surfaces: the pay pages (`/pay`, `/m`, `/r`), the merchant mini-apps that open inside Messages (`/setup`, `/bank`, `/w`, `/confirm`, `/shop`), the QR sticker, and the static card preview images. All mobile, one column, the amount as the largest element. No dashboard, no design system beyond ~5 shared components.
